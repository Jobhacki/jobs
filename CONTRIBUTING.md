# Contributing to the JobHacki Jobs list

Thanks for helping people find the right job list. Suggestions and link reports help keep this index useful.

## What belongs in this list

This index covers remote, entry level, nursing, healthcare, tech, AI, sales, customer service, internship, finance, marketing, trucking, and logistics roles.

## Suggest a job

Suggest a role with its exact title, employer's own apply link, and the category where it belongs.

[Open the Add a job form](https://github.com/Jobhacki/jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the category, role title, employer, broken link, and what the employer's page says.

[Open the Report a dead link form](https://github.com/Jobhacki/jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
